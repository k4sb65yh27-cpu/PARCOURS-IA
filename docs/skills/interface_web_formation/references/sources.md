# Sources du skill interface_web_formation

Synthèse rédigée le 27/11/2026 à partir des cinq skills retenus pour les interfaces web de formation. Aucun passage n'est copié ; les règles sont reformulées et adaptées.

| Rang | Skill source | Licence | Repris | Écarté |
|---|---|---|---|---|
| 1 | frontend-design (Anthropic, skill officiel) | Apache 2.0 (LICENSE.txt du skill) | Ancrage dans le sujet, retenue, un seul élément mémorable, textes d'interface (verbes d'action, états vides) | Direction esthétique libre : la référence du projet prime |
| 2 | html-soigne (SATT, synthèse Vercel Web Interface Guidelines, Make Interfaces Feel Better, Hallmark, Impeccable) | Sources MIT ou Apache 2.0, voir son sources.md | Conteneur plafonné aux grandes largeurs, mesure 65 à 75 caractères, focus, aria-live, typographie française | Règles d'e-mail HTML |
| 3 | pages-html-sobres (SATT) | Sources MIT ou Apache 2.0 | Mode « Opérer » (densité, constance des contrôles), états des contrôles, contrôle à deux largeurs | Palette SATT par défaut (la PWA a sa palette propre) |
| 4 | animation-ludique-pwa (SATT, synthèse de 18 dépôts) | Dépôts MIT, Apache 2.0 pour Babylon.js | Grammaire du mouvement et des sons, budget PWA | Choix de bibliothèques (aucune ajoutée ici) |
| 5 | ui-ux-pro-max | Voir le dépôt d'origine | Priorités (accessibilité, tactile, mise en page responsive, navigation à cinq onglets au plus) | Base de données et scripts de recherche, absents de la copie installée ; orientation marketing |

Écartés du classement : anti-slop-livrables (centré sur PPTX, DOCX et PDF ; son plancher HTML renvoie à html-soigne) et revue-anti-slop (méthode de revue a posteriori ; son contrôle sur rendu est repris à l'étape 4 de la méthode).

Apport propre à ce skill : le tableau des zones par largeur et par type d'écran, la colonne d'accompagnement, et la mesure de couverture du premier écran.
